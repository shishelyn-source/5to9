# After Hours — School Sleepwear

A responsive storefront prototype for a school community sleepwear collection.

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Prototype features

- Product grid with category filters and search
- Quick add, bag quantities, and subtotal
- Sign up and log in screens using a school email address
- Wishlist buttons, newsletter feedback, and checkout handoff message
- Responsive layout with navy, pink, and white styling

## Before launch

Accounts and the bag are stored in the current browser using `localStorage`. This is a visual prototype only: it does not verify school email ownership and must not be used to collect real passwords. Replace account handling with a secure authentication service, and connect checkout to a payment provider and order backend before accepting orders. Product imagery currently loads from Unsplash.
